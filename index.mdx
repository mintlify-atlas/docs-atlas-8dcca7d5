AI Surfer is a cinematic, neon-surf web platform built for businesses ready to automate their marketing, sales, and operations with AI. It combines a React + Vite frontend with an Express backend, OpenAI-powered agents, Supabase data storage, and Cloudflare edge deployments — all under one roof at [otdaisurfer.surf](https://otdaisurfer.surf).

## Get Up and Running

<Steps>
  <Step title="Clone & install">
    Clone the repository and install dependencies with `npm install`.
  </Step>
  <Step title="Configure environment">
    Copy `.env.example` to `.env` and fill in your Supabase, Stripe, and OpenAI credentials. See [Environment Setup](/environment-setup).
  </Step>
  <Step title="Start the dev server">
    Run `npm run dev` for the Vite frontend and `npm run server:dev` for the Express AI backend.
  </Step>
  <Step title="Explore the platform">
    Visit `http://localhost:5173` to see the frontend, and `http://localhost:3001/health` to verify the backend is running.
  </Step>
</Steps>

<Note>
  AI Surfer requires Node.js ≥ 18 and npm ≥ 9. Make sure both are installed before running any commands.
</Note>
